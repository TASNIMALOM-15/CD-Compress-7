# Telegram Video Compressor (server-side FFmpeg)

Personal Telegram bot: send a video, pick quality + FPS, a queue compresses it one at a time with FFmpeg on the server and sends the result back.
Built for Render Free (512 MB RAM / 0.1 CPU). Uses MTProto (Pyrofork) so files up to ~2 GB work.
See GUIDE_BN.md for the full Bengali setup guide.
